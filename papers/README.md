## Newer centrality manuscript

`aesc-revised-source/` contains the newer manuscript's LaTeX source, bibliography, class/style files, and referenced figures, copied from `/Volumes/Samsung 980/tgtp/paper` on 13 September 2026. That directory did not contain a compiled manuscript PDF.

The revised manuscript is titled *Accelerating Spanning-Centrality Approximation with Sampling-Aware Vectorized Random Walks*. Its sampler correction supersedes the older arXiv version for the seminar. Section 5 explicitly says the historical comparative experiments require remeasurement. The historical PDF is retained for reference, not as performance evidence for the corrected method.
